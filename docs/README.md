# CardBoxGen Web App

This folder is the static GitHub Pages app.

Runtime files:

- `index.html`
- `app.js`
- `style.css`
- `i18n/*.json`
- `cardboxgen_bundle.py` generated by `python tools/sync_docs.py`

The app loads Pyodide in the browser and imports `cardboxgen_bundle.py`. No backend is required.

## Local Preview

From the repo root:

```bash
python tools/sync_docs.py
python -m http.server 8000
```

Open <http://localhost:8000/docs/>.

## Freshness Check

```bash
python tools/sync_docs.py --check
```

This fails if `docs/cardboxgen_bundle.py` no longer matches the package source.

## GitHub Pages

The Pages workflow uploads `docs/` as the deploy artifact. In GitHub repository settings:

- Settings -> Pages
- Source: GitHub Actions
