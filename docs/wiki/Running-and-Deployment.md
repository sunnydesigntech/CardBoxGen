# Running and Deployment

## Local Web Preview

From the repository root:

```bash
python tools/sync_docs.py
python -m http.server 8000
```

Open:

```text
http://localhost:8000/docs/
```

## CLI

```bash
python -m cardboxgen --preset tray_open_front --inner-width 135 --inner-depth 90 --inner-height 80 --thickness 3 --kerf 0.2 --clearance 0.15 --out out.svg
```

Calibration:

```bash
python -m cardboxgen --calibration --thickness 3 --kerf 0.2 --out calibration.svg
```

## Tests

```bash
python -m pytest -q
python -m pytest -m slow -q
python examples/generate_examples.py
python tools/sync_docs.py --check
```

## GitHub Pages

The Pages workflow deploys the `docs/` folder. Repository settings should use:

```text
Settings -> Pages -> Source: GitHub Actions
```

Live app:

```text
https://sunnydesigntech.github.io/CardBoxGen/
```

Direct launcher entry:

```text
https://sunnydesigntech.github.io/CardBoxGen/exec/
```

## Source of Truth

Generator logic lives in `cardboxgen/`. The browser bundle `docs/cardboxgen_bundle.py` is generated by `tools/sync_docs.py` and should not be edited by hand.
